# Unified research and scheduled jobs

Study and research requests use the same composer, with reusable skills for paper review, exam preparation and quizzes. New work starts in Agent > Research. One form configures the request, saved lead and specialist instructions, sources/files, optional public web access, tool permissions, and schedule/delivery. Automatic team uses the personal-agent delegation engine; One agent uses that same runtime without delegation. Tasks & schedules lists saved jobs and offers Run now, Pause/Resume and Cancel. New scheduled task returns to the same Research form with scheduling expanded. Dashboard shows activity, answers, report export and save-to-Notes actions.

Run `npm run verify:agents -- agent-orchestration.spec.ts research-team.spec.ts agent-overview.spec.ts` with isolated deterministic fixtures. The orchestration journey checks actual notebook/web specialists, tool scope, cited results, traces, saving its report to Notes and retaining the save marker after reload, and mobile layout. The schedule journey uploads a synthetic text file, saves a future recurring team job, checks stored role instructions and source selection, pauses/resumes it, reloads saved browser instructions and confirms no inference occurs before its due time. Navigation verifies that Tasks & schedules has no competing composer.

Earlier planned research reports remain available through Dashboard. The old planned-engine API contracts and model routing are covered by `tests/planned-research.test.ts`; that engine is no longer the default new-work UI. Prior live planned-team browser acceptance scripts describe the previous creation flow and need migration before use. Fixture success does not establish live model quality or provider availability. Never run live acceptance without explicit provider/data authorization.
